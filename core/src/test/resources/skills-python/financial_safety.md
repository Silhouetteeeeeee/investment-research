第四问：财务安全吗？会不会因为一次危机就撑不住？

判断标准：不是看资产负债率高低，而是看坏年份来临时它能不能自己活下来。重点是有息负债、短期到期的债务、现金和利息支出，以及商誉、应收、存货这些"看着是资产、出事时变不成钱"的项目。

逐项看：
1. 有息负债：短期借款、一年内到期非流动负债、长期借款、应付债券、租赁负债合计；短期有息负债占多少，货币资金能不能覆盖。资产负债率只是参考，不同行业差异很大，不要机械套用"超过 70% 就不安全"。
2. 利息保障：利润总额加利息费用，再除以利息费用。低于 3 倍要警惕，低于 1.5 倍说明利润稍一下滑就还不上利息。工具会标明用的是利息费用还是财务费用近似。
3. 营运资金：应收账款、存货的增速是否持续快于营收；经营现金流/净利润是否长期低于 1。赊销冲收入、压货堆库存，最后都会变成减值和坏账。应付账款、合同负债/预收款反映对上游和下游资金的占用，要和应收、存货一起看：占用上下游资金本身不是有息负债，但账期异常拉长可能是议价能力或资金紧张的信号。银行/保险的经营现金流由存款、保费变动驱动，应收、存货也不是同一口径，这些指标对它们不可比，写「口径不可比」。
4. 商誉：绝对额与占净资产比例。占比高、且被并购标的增长乏力时，减值会直接吃掉利润；用公告交叉验证并购与减值。
5. 股东质押：用 get_pledges 看最新质押比例、质押股数与市值、近一年变化和区间峰值。质押比例高、持续上升或大股东高比例质押，可能反映资金压力与控制权风险；但质押不等于违约，要结合质押用途、平仓线（数据没有时写「资料不足」）、股价和公告判断。
6. 股东权益稀释：定增、可转债、大额股权激励会摊薄每股价值；数据里没有股本变动时写「资料不足」，有公告就引用公告。
7. 压力测试：假设营收连续 2–3 年下滑 20%–30%、毛利率再降 5–10 个百分点、融资环境收紧，经营现金流是否仍为正、现金能否覆盖短期债务与利息。缺少分项成本数据时，给出测算假设并标明是估算，不要伪装成精确结果。

回答结构：
1. 先列安全垫：货币资金、有息负债、短期有息负债、利息保障倍数、商誉占净资产比例、应收/存货同比。
2. 再做 2–3 个坏年份情景的压力测试，写清假设。
3. 结论落在三档之一：安全（现金覆盖短债、利息保障充足）/ 需要关注（某一项偏紧）/ 脆弱（短债覆盖不足或利息保障过低），并说明触发条件。
4. 给 2–3 条可验证的观察指标。

取数：get_finance 取有息负债、利息保障、商誉、应收/存货同比、应付账款与合同负债；需要看借款期限结构、其他应收/应付款或权益科目时看 balance_detail；get_financial_history 看多年有息负债、负债率与现金流；get_pledges 看股东质押比例、质押股数/市值、近一年变化与峰值；get_announcements 找商誉减值、定增、可转债、股权激励。对照另一家公司时分别取数、分别引用。

禁止：
- 只看资产负债率就下结论，或把高负债直接等同于危险。
- 对银行、保险等金融机构套用有息负债、利息保障、经营现金流/净利润、应收/存货口径（存款不是有息负债，利息支出也不是费用），这类公司明确写「口径不可比」。
- 不区分受限资金；数据没有时写「资料不足」。
- 把股权质押比例高直接等同于违约或爆仓，或忽略质押比例持续上升。
- 用估算的压力测试冒充财报事实。
