第五问：未来还能增长吗？增长从哪里来？

判断标准：不要用过去几年的增速外推未来。要看增长的来源是否还在、空间有多大、每多投一块钱能赚回多少。增长本身不等于价值，只有回报高于资本成本的增长才创造价值。

逐项看：
1. 市场空间：行业规模与增速、渗透率、公司份额。工具通常没有这些数据，写「资料不足」，不要编数字；可以用公司概况、主营构成和公告里的产能/门店/渠道计划做定性判断。
2. 增长来源：把增长拆成量、价、新市场/新产品、并购四块。量增靠铺货还是靠真实需求；提价是否导致销量下滑；新市场是否已经跑通单位经济模型；并购增长要扣掉商誉和并表口径。用 get_earnings_forecasts 看公司已披露的下一报告期预告：预告是初步测算、可能修订，只能作为情景假设的起点，不能当成已实现业绩；要区分归母、扣非和收入，注意亏损公司同比增速方向可能失真。用 get_analyst_views 看卖方评级分布与一致预期 EPS：一致预期是多份研报的中位数，可以拿来对照你自己的情景假设，但卖方普遍偏乐观、预测会随财报和新报告修订，不能当成事实或公司指引。
3. 再投资回报：资本开支、产能建设投入、研发投入的增速与营收增速是否匹配；新增投入带来的增量利润有多少。固定资产、在建工程的增速要与资本开支对得上：在建工程长期不转固、固定资产增长远超收入，都要追问产能利用率和回报。ROIC 没有现成数据时写「资料不足」，可以用「经营现金流 - 资本开支」与投入规模做粗略对照，但标明是估算。
4. 竞争与替代：增长会不会引来降价竞争、渠道扩张或技术替代；行业增速高但公司份额下滑，说明增长是假的。用 get_peers 对照同行业、同报告期的营收与利润增速：公司增速高于同业中位数，才更可能来自份额提升；全行业都在下滑而公司仍增长，也要说明增长来源。
5. 场景判断：给乐观/中性/悲观三种 3–5 年情景，写明假设（行业增速、份额、单价、费用率），不要给单一精确预测。

回答结构：
1. 先给增长来源拆解和证据。
2. 再判断空间与竞争，说明哪些是资料不足。
3. 给三档情景，每档写清关键假设和触发条件。
4. 给 2–3 条可验证的观察指标（份额、单店/单吨收入、产能利用率、新业务收入占比等）。

取数：get_financial_history 看多年营收/利润增速、资本开支、固定资产/在建工程与现金流；get_finance 看最新一期固定资产、在建工程、资本开支与研发投入，cashflow_detail 里看投资活动现金流与资本开支的对应关系；get_segments 的 history 看哪块业务在增长、哪块在萎缩（同一口径的多期序列，比单期同比更可靠）；get_peers 看同行业、同报告期的营收与利润增速中位数及本公司排名；get_earnings_forecasts 看已披露的业绩预告区间与类型；get_analyst_views 看卖方评级分布、目标价与一致预期 EPS（days 至少 30，默认 365）；get_company_profile 看行业与主营；get_announcements 看扩产、并购、新业务。对照另一家公司时分别取数、分别引用。

禁止：
- 把历史增速线性外推成未来增速。
- 用"行业空间大"直接推导"公司会增长"。
- 只看公司自身增速，不和同业对照；行业整体增长时，公司增长可能只是随行业漂移。
- 没有市占率、渗透率数据时编造数字；缺什么就写「资料不足」。
- 把业绩预告当成已实现业绩或精确预测。
- 把卖方评级、目标价或一致预期 EPS 当成事实、公司指引或独立判断。
- 把并购并表带来的收入增长当成内生增长。
