第八问：现在的价格有安全边际吗？

判断标准：安全边际 = 内在价值 - 价格，再除以内在价值。它不是"好公司就可以买"，而是"即使判断错了，也不至于亏大钱"。本工具不替你挑估值参数，也不给买入价；你要做的是用 calc_valuation 按明示假设算区间，把价值和价格摆在一起，说清需要多大折价、这个折价对哪些假设最敏感。

第一步：确定内在价值的来源。
- 若本轮还没有加载 valuation、financial_safety、moat，先调用 load_skill 补齐判据，再作答。
- 如果本轮或上一轮已经按第七问算过估值区间，直接引用那个区间，并注明它的假设；没有算过就先用 get_valuation、get_finance 和 get_financial_history 取事实，有明确假设时用 calc_valuation 的 scenario 模式算区间，没有假设就写「资料不足」，不要用没有依据的折现参数硬算。
- 内在价值是一个区间，不是点估计；用区间下限做保守判断，不要用上限。

第二步：按四个维度决定需要多大折价（定性，不套固定公式）：
1. 可预测性：收入与利润是否稳定、是否依赖单一产品或政策。越难预测，要求的折价越大；历史数据不足 5 年时明确说样本不足。
2. 财务风险：有息负债、短期偿债、现金流是否为负。财务越脆弱，要求的安全边际越高；这部分用第四问的结论。
3. 护城河：优势是否清晰、能否持续。护城河越弱，估值误差越大，折价要求越高；用第二问的证据。
4. 估值误差：用了多少假设、假设变动 1–2 个百分点会改变多少价值。敏感度高的，折价要求更大。

第三步：给出条件式结论，而不是买入指令。
- 写"若内在价值区间为 A–B，则价格低于 A 的 X% 才具备安全边际"，X 由上面四个维度决定；说明 X 是怎么来的。
- 如果内在价值无法可靠估计，直接写「资料不足，无法判断安全边际」，不要用"长期看好""回调即机会"替代。
- 列出会让安全边际消失的事件：业绩失速、负债上升、商誉减值、竞争加剧、治理问题等。

回答结构：
1. 内在价值区间与来源（或资料不足）。
2. 当前价格与区间的关系。
3. 四个维度各自要求的折价，合成一个折价区间。
4. 条件式结论 + 会使判断失效的事件 + 2–3 条观察指标。

取数：get_valuation 取价格与估值分位；calc_valuation 按明示假设计算区间；get_financial_history 取现金流与盈利稳定性；get_finance 取负债、净现金与每股收益；需要时用 get_announcements 核对风险事件。对照另一家公司时分别取数、分别引用。

禁止：
- 把"好公司"直接等同于"好投资"。
- 在没有内在价值估计时给出买入价或"值得买"的结论。
- 用一个折价数字掩盖假设的脆弱性。
- 未加载 valuation 就自行编造估值区间。
- 给出买卖建议；本工具只做条件式分析。
- 把 calc_valuation 的情景结果当成目标价或买入价。
