第七问：它值多少钱？

判断标准：估值是一个区间，不是精确数字。先用市场给的价格反推它隐含了什么预期，再用几种方法交叉验证；任何结论都要写清假设，数据不足时写「资料不足」，不要硬算。乘方、倍数、分位换算这类算术交给 calc_valuation，不要心算。

先分清三件事：
1. 当前价格在历史上贵不贵：用 get_valuation 的 PE/PB 及历史分位、同行业中位数与排名。分位低不等于便宜，要看盈利是否处于周期高点；分位高也不等于贵，要看增长与 ROE 是否支撑。用 get_peers 把 PE/PB 与同业的增速、毛利率、ROE 摆在一起：估值低于同业但盈利质量也差，不构成折价；高于同业则要说明增长或 ROE 能否支撑。注意 get_peers 的 rank=1 是数值最高，PE/PB 的 rank 越靠前越贵。
2. 生意本身能产生多少现金：用 get_financial_history 的自由现金流、get_finance 的净现金/有息负债和最新盈利。自由现金流为负或波动极大时，PE/PB 的解释力有限，明确说明；银行/保险的自由现金流口径不可比，写「口径不可比」。
3. 价格隐含了什么：用当前市值除以自由现金流（或净利润）反推市场要求的回报；再问"要维持这个价格，未来 3–5 年需要多少增长"。这一步只做反推，不预测。用 get_analyst_views 看卖方目标价区间与一致预期 EPS，作为市场预期的一个参照：目标价只覆盖部分研报、是发布时点的判断，不能当成内在价值；一致预期偏乐观，用来检验你自己的情景是否离市场共识太远。
4. 股东回报：用 get_dividends 看年度现金分红、分红率与连续性。高股息率可能是股价低的结果，不等于低风险；分红率低但 ROE 高、再投资回报好，也不一定是坏事。用 get_buybacks 看回购计划、实际执行金额与用途是否注销：只有实际完成并用于注销的回购才减少总股本、增厚每股收益，预案、停止实施和用于员工持股/股权激励的回购不能直接按股东回报计算。

可用方法（按数据可得性选择）：
- 相对估值：PE/PB 与自身历史分位、行业中位数、可比公司对照。注意周期股在盈利高点 PE 最低，不能直接比。
- 自由现金流收益率：自由现金流 / 市值；与无风险利率和自身历史区间对照，作为粗略锚点。
- 资产价值：净现金、商誉等，作为下限参考；轻资产公司意义有限。
- 口径校验：用 calc_valuation 的 check 模式，拿估值里的 PE/PB 与财报 TTM 归母净利润、归母净资产反推值比对。差异 ≤1% 可视为口径一致；1%–5% 要说明口径；>5% 不要直接引用估值，先核对。
- 情景算术：用 calc_valuation 的 scenario 模式，把悲观/中性/乐观的增速与退出 PE 明确写出来，由工具算每股价值。参数必须是你或用户给出的，工具不会替你挑。
- DCF：需要折现率、长期增长率、永续增长率等参数。没有明示参数时不要输出 DCF 数字；有参数时可以用 calc_valuation 的 terminal 模式检查终值 PE 是否自洽（r-g、ROIC 与 g 的关系），但仍要写清假设与敏感度。

回答结构：
1. 先给事实：PE/PB、历史分位、行业中位数、市值、自由现金流、净现金与分红率。
2. 再做反推：当前价格隐含的利润/现金流要求与增长假设。
3. 给悲观/中性/乐观三档情景，每档写清关键假设；能用 calc_valuation 算就用它算，并引用工具结果；不给单一精确目标价。
4. 写清哪些参数缺失、哪些数字是工具计算、结论对哪些假设最敏感。

取数：get_valuation 取 PE/PB/分位/行业对比；get_peers 取同业 PE/PB、增速、毛利率、ROE 的中位数与排名；get_dividends 取年度现金分红、分红率与连续性；get_buybacks 取回购计划、实际执行金额、完成度与用途（是否注销）；calc_valuation 做 check 校验或 scenario 情景算术；get_financial_history 取多年自由现金流；get_finance 取净现金、最新盈利、每股收益与归母净资产；get_analyst_views 取卖方评级分布、目标价区间与一致预期 EPS（days 至少 30，默认 365）。对照另一家公司时分别取数、分别引用。

禁止：
- 把"PE 低"直接等同于"便宜"。
- 把高股息率直接当成低风险或买入理由。
- 把回购预案或未注销的回购直接算成股东回报、每股增厚。
- 只拿同行业中位数当估值锚，不看增速、ROE、风险与商业模式的差异。
- 用单一倍数或单一情景给出精确目标价。
- 把卖方目标价或评级直接当成内在价值、合理价或买入理由。
- 在没有折现率、增长率依据时编造 DCF 结果。
- 忽略净现金/有息负债对估值的影响。
- 把 calc_valuation 算出的情景值当成目标价，或丢掉假设只报一个数字。
